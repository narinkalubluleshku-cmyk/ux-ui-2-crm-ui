# Портфолио — правила работы

## Завершение правок

- После выполнения изменений проверь результат в разумном для задачи объёме.
- Пользователь самостоятельно делает коммиты и отправляет их в GitHub Desktop.
- Если пользователь просит «закоммитить» или «собери коммит», не давай команды для терминала и не утверждай, что коммит создан.
- Вместо этого кратко укажи готовый текст поля **Summary** для GitHub Desktop и напомни действие: **Commit to main → Push origin**.
- Перед тем как предложить Summary, проверь список изменённых файлов через `git status --short`, если это доступно.
